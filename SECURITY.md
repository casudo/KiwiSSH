# Security Policy

> [!IMPORTANT]
> Security Policy as of October 2026

## Supported Versions

The major version 2.x.x will regularly receive security updates. Refrain from using unsupported versions.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :x:                |
| 2.x.x   | :white_check_mark: |

## Reporting a Vulnerability

If you've found a critical vulnerability, please contact me directly via [security@kida.one](mailto:security@kida.one).
Please include the project name and a detailed description about your finding. Make sure to read your mails in case I'll have questions.
